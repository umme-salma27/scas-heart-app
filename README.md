# SCAS heart-disease risk app (research prototype)

Streamlit app for the SCAS stacked model: probability of angiographic coronary artery disease with exact Shapley explanations, risk ranges for values that were not measured, a robustness badge, a novelty warning and local recalibration. See `model_card.md`.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.

Deploy on Streamlit Community Cloud: main file `app.py`, Python 3.13.15.
